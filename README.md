# Парсер библиотеки knigofil.org

Скрипт скачивает обложки и тексты книг с сайта [knigofil.org](https://knigofil.org/).

## Что делает скрипт

- Скачивает обложки книг с главной страницы в папку `images11/`
- Собирает информацию о книгах: название, автор, жанр, год
- Скачивает тексты книг из топ-100 в папку `books/`

## Как установить

Python 3.10+ обязателен.

Клонируйте репозиторий и установите зависимости:

```bash
pip install requests beautifulsoup4 sanitize-filename
```

## Как запустить

```bash
python main.py
```

## Результат

После запуска появятся две папки:

| Папка | Содержимое |
|---|---|
| `images11/` | Обложки книг в формате `.jpg` |
| `books/` | Тексты книг в формате `.txt` |

## Зависимости

| Библиотека | Назначение |
|---|---|
| `requests` | HTTP-запросы к сайту |
| `beautifulsoup4` | Парсинг HTML-страниц |
| `sanitize-filename` | Очистка названий файлов от недопустимых символов |
